# Hearth

A clean home screen for Amazon Fire TV. No sponsored rows, no autoplaying ads, no tracking: your apps, a clock,
and a glow in the colour of whatever you're about to watch.

| Before | After |
|---|---|
| ![Stock Fire TV home with a sponsored banner](docs/before.jpg) | ![Hearth with the Ember theme](docs/after-ember.jpg) |

![The Fireplace: a real wood fire with the clock above it](docs/fireplace.jpg)

Fire OS won't let another app become Home, so Hearth doesn't fight it: a small accessibility service watches for
Amazon's home screen and opens Hearth in its place. Amazon's launcher stays installed and enabled, and pressing
Home twice in a row still gets you to it.

## What it does

- **Debloat.** Disables Amazon's content recognition (ACR), shopping, telemetry, tutorials and preloads with
  `pm disable-user`. Nothing is uninstalled and everything comes back with one command.
- **Home.** Builds the launcher from source and installs it, with `FireHomeService` sending the Home button to it.
  The service only sees window changes from Amazon's launcher and Appstore. It reads no screen content and filters
  no keys, so held Volume keeps repeating.
- **Fireplace.** A real wood fire, looped without a seam, with a thin clock drifting above it. Open the
  Fireplace tile for it with the crackle, or set `"fireplace": true` in a theme to make it the idle screen.
- **Ad-blocking DNS**, optional: Private DNS through AdGuard for the whole TV.
- **Themes** you can switch without a rebuild.

## Install

On the TV: Settings > My Fire TV > About, press OK on the first entry seven times, then back to Developer options
and switch **ADB debugging** on.

On a Mac or Linux machine on the same network, with JDK 17 and the Android SDK (platform 34, build-tools 34.0.0):

```bash
TV_HOST=192.168.1.50 DNS=1 THEME=themes/ember ./install.sh
```

Accept "Allow USB debugging?" on the TV when it asks. The script backs up the TV's packages and settings to
`backup/`, applies the debloat list for your model if there is one in `lists/`, builds and installs the launcher,
and points Home at it. Switch ADB debugging off when you're done.

To undo all of it:

```bash
TV_HOST=192.168.1.50 ./uninstall.sh
```

`KEEP_DEBLOAT=1` removes only the launcher.

## Themes

| Theme | Look |
|---|---|
| `themes/ember` | Charcoal with a low ember glow and drifting sparks; the focused app's colour washes down from the top |
| `themes/midnight` | True black for OLED, a quiet rim highlight, no screensaver glow |
| `themes/daybreak` | A sky backdrop that follows the time of day, frosted dock |

```bash
TV_HOST=192.168.1.50 tools/theme.sh themes/midnight
TV_HOST=192.168.1.50 tools/theme.sh --reset
```

A theme is a `config.json` plus an optional `wallpaper.jpg`. The Ember wallpaper is generated by
`themes/ember/make_wallpaper.py` (Pillow and NumPy).

## Tested on

Amazon Fire TV AFTHY7ABBA (`ginza`), Fire OS 8.1.8.5 / Android 11, build RS8185.3885N. Other Fire OS 7 and 8 TVs
should work for the launcher half; the debloat list is per model.
